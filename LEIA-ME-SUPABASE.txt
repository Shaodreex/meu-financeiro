MEU FINANCEIRO v2 — SINCRONIZAÇÃO SUPABASE

1) No Supabase, abra seu projeto > SQL Editor.
2) Crie uma nova query, cole todo o conteúdo de setup_supabase.sql e execute.
3) No projeto, use o botão Connect ou Settings > API Keys para copiar:
   - Project URL
   - Publishable key (sb_publishable_...)
4) Abra supabase-config.js e substitua os dois textos COLE_AQUI...
5) Envie para o GitHub os arquivos atualizados desta pasta.
6) Aguarde o GitHub Pages publicar.
7) PRIMEIRA MIGRAÇÃO: entre primeiro no aparelho que contém seus dados mais completos. Se a nuvem estiver vazia, esse aparelho fará a carga inicial. Depois entre nos demais aparelhos com a mesma conta.

SEGURANÇA
- A Publishable Key pode ficar no código cliente quando o RLS está configurado.
- NUNCA use Secret Key ou service_role neste projeto/GitHub.
- A tabela usa Row Level Security: cada usuário só acessa a própria linha.

FUNCIONAMENTO
- Toda alteração é salva primeiro no dispositivo.
- Quando há internet e login, o estado é sincronizado com o Supabase.
- O app verifica atualizações ao voltar para a tela e a cada 15 segundos enquanto está aberto.
- Em caso de falta de internet, você continua usando os dados locais e a sincronização volta quando a conexão retornar.
